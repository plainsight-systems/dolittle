The build

First, a pair we can run.

Qwen3 8B and its NLA pair have run on a 24 GB RTX 3090 Ti. Next comes the C++/CUDA engine and a browser interface for inspecting a generation. Explanations and explorations will accompany the work; milestones will mark capabilities we can use.

Reference runs complete. NVIDIA first; Metal planned next. AMD support is undecided. The engine and live interface are still to come.
