# Project website

This directory is for Dolittle's public project website, following Cradle and
Serenity: project explanation, artwork, build/run guidance, and milestone
writing. The site should be useful without running a GPU engine.

The live inference interface belongs in `app/` and is served by a running
Dolittle deployment. Site implementation, generator selection, hosting, and
publication are still pending. The initial artwork is
`../docs/assets/dolittle-readme.png`; milestone prose belongs in
`../docs/writeups/`.
