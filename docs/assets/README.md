# Project artwork

`dolittle-readme.png` is the initial README and project-site banner, generated
2026-10-16 with OpenAI's built-in image generation tool. It is 2172 × 724 pixels
with an opaque background. The original PNG is preserved without resizing or
retouching. It is referenced by the root README.

The illustration uses the midnight-blue, antique-gold, and textured-paper
visual language of Cradle and Serenity. A parrot speaks toward a brass
listening instrument as glowing marks become handwriting above a notebook.
The metaphor connects Doctor Dolittle's communication with animals to
translating model activations into readable language.
