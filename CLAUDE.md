# Dolittle entry point

Read `AGENTS.md`, then `docs/process/MEMORY.md`, `docs/process/QUEUE.md`, and
`docs/process/workflow.md`. If `CLAUDE.local.md` exists, use it for local context
and never commit it.

Current engineering decisions belong in the repository's process documents;
research belongs in `docs/research/`. Conversation summaries, approvals and
development history belong in ignored local notes. Do not depend on chat
history as project memory.
